Privacy Policy

Top Arena · effective 27 October 2026

Scope

Top Arena is a private tool used only by the owner of one YouTube channel to publish its own videos. It has no other users and does not collect information from viewers or from anyone else.

Google user data it accesses

With the channel owner's consent (Google OAuth), Top Arena uses these YouTube Data API permissions:

  • youtube.upload: to upload the owner's rendered videos to the owner's channel and schedule them.
  • youtube.readonly: to read the channel name and the view, like and comment counts of the videos Top Arena uploaded.

It does not read private messages, subscribers' personal data, watch history or any data of other channels.

Storage and sharing

  • The OAuth authorization (refresh token) is stored only on the owner's private server, in a file readable only by the Top Arena service. It is never published or sold.
  • Video links and their view, like and comment counts are sent only to the owner's private Telegram chat as status messages.
  • No Google user data is shared with third parties, used for advertising or used to train AI models.

Google API Services User Data Policy

Top Arena's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Rendered video files are deleted from the server a few days after upload. The owner can revoke Top Arena's access at any time at myaccount.google.com/permissions; deleting the stored authorization file on the server removes all stored Google data.

Contact

Questions about this policy can be sent to the channel owner through the contact details on the YouTube channel's About page.
